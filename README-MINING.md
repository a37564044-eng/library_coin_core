# LARB Mainnet Mining

## 1. Wallet
Jalankan miner:

./larb_miner

Saat pertama kali dijalankan, buat password wallet.
Wallet terenkripsi disimpan di:

~/.larb/wallet.dat

## 2. Mining
Miner akan otomatis:
- membuka wallet
- memuat blockchain
- mengambil reward sesuai height
- melakukan Proof-of-Work
- memvalidasi block
- menyimpan block ke chain

## 3. Menjalankan node
Jalankan:

./larb_node

Port default:

8333

## 4. Reward
Initial block reward:

50 LARB

Halving setiap:

210000 blocks

## 5. Backup
Backup file:

~/.larb/wallet.dat

Password wallet wajib disimpan oleh pemilik wallet.

Kehilangan wallet atau password dapat menyebabkan akses ke reward hilang.
